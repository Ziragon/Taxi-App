## Документация проекта «Arbuz Express»

### 1. О приложении

**Arbuz Express** — это клиент-серверное мобильное приложение для заказа такси, разработанное на фреймворке Flutter. Приложение предоставляет пользователям возможность быстро найти такси, построить маршрут, рассчитать стоимость поездки с учётом погодных условий и выбранного тарифа, а также управлять способами оплаты и просматривать историю поездок.

**Основные возможности:**
- Авторизация и регистрация (клиент / водитель)
- Отображение интерактивной карты с маршрутом
- Поиск адресов через геокодер (OpenStreetMap Nominatim)
- Построение автомобильного маршрута (OSRM)
- Расчёт тарифа на основе расстояния, погодной надбавки и выбранного класса (Эконом / Комфорт / Бизнес)
- Детальная статистика поездки (количество машин рядом, надбавки, итоговая сумма, статус водителя)
- Выбор способа оплаты (наличные / безналичный расчёт)
- Личный кабинет с возможностью смены аватара, просмотра истории, способов оплаты и поддержки
- Роль водителя (добавление данных автомобиля, баннер верификации)

### 3. Архитектура приложения

Приложение построено по **модульному принципу** с разделением на:

- **Экраны (screens)** – отвечают за отображение и пользовательские сценарии.
- **Виджеты (widgets)** – переиспользуемые компоненты интерфейса (стеклянные карточки, кнопки, поля ввода и т.д.).
- **Кастомные компоненты карты** – маркеры, выбор тарифа.
- **Утилиты** – форматтеры для номера карты и срока действия.

**Навигация:** `MaterialPageRoute` + стейт-менеджмент через `setState` (без внешних библиотек типа Bloc / Riverpod).

### 5. Ключевые экраны и функциональность

#### 5.1. Экран авторизации (`AuthScreen`)
- Поля: номер телефона (с префиксом +7), пароль (минимум 6 символов, без дополнительной валидации на этом этапе).
- Кнопка «Войти» активна только при заполненных полях.
- Кнопка «Зарегистрироваться» ведёт на выбор роли.
- Стиль: стеклянная карточка (`GlassCard`) с декоративными «сферами».

#### 5.2. Регистрация (`RoleSelectionScreen` → `RegistrationDetailsScreen`)
- Клиент заполняет: ФИО, телефон, номер карты, CVV, срок действия, пароль (с проверкой сложности: заглавная буква, цифра, спецсимвол).
- Водитель дополнительно вводит: марку, модель, госномер (с регулярным выражением), год выпуска, цвет.
- После успешной регистрации происходит переход на `HomeMapScreen` с флагом `showVerificationBanner` для водителя.

#### 5.3. Главный экран с картой (`HomeMapScreen`)
- Используется `FlutterMap` с источником тайлов OpenStreetMap.
- **Точки:**
  - Отправление – определяется по GPS или выбором из поиска (жёлтый маркер `PickupMarker`).
  - Назначение – через поиск, долгое нажатие на карту или обратный геокодинг (оранжевый маркер `DestinationMarker`).
- **Маршрут:** загружается через OSRM, отрисовывается жёлтой линией (`PolylineLayer`). Камера автоматически подстраивается под обе точки и весь путь.
- **Поиск адресов:** через Nominatim с задержкой debounce 350 мс, результаты отображаются в выпадающем списке (`SearchResultsList`).
- **Нижняя панель:** сворачиваемая стеклянная карточка, содержащая поля «Откуда» / «Куда едем?». При выборе назначения появляется блок с тарифами и кнопкой статистики.
- **Тарифы:** три варианта (Эконом, Комфорт, Бизнес) с фиксированными надбавками (0 / +170 / +550 ₽).
- **Расчёт стоимости:**
  - Базовая стоимость = 50 ₽
  - Тариф за расстояние = расстояние (км) × 30 ₽
  - Погодная надбавка: < -10°C → +100 ₽, < 0°C → +40 ₽, > 30°C → +80 ₽
- **Информация о машинах рядом:** вычисляется псевдослучайно на основе расстояния (от 5 до 80 машин).

#### 5.4. Статистика поездки (`StatsBottomSheet`)
- Вызывается по нажатию на кнопку с шестерёнкой (появляется только после выбора адреса назначения).
- Отображает: количество машин рядом, надбавку за погоду, тариф за расстояние, минимальную стоимость, выбранный тариф, надбавку за тариф, статус водителя («трезвый / к сожалению»), случайное имя водителя, итоговую сумму.
- Переключатель способа оплаты (Наличные / Безнал).
- Кнопка «Понятно» закрывает модальное окно.

#### 5.5. Профиль (`ProfileScreen`)
- Возможность установить аватар из галереи (`image_picker`).
- Отображение статистики (количество поездок, рейтинг).
- Меню: история поездок, способы оплаты, поддержка.
- Кнопка выхода с подтверждением.

#### 5.6. История поездок (`RideHistoryScreen`)
- Примеры поездок (захардкожены для демонстрации).
- Каждая карточка содержит: фото водителя (DiceBear API), модель авто, номер, тариф, имя водителя, ID поездки (можно скопировать долгим нажатием).

#### 5.7. Способы оплаты (`PaymentMethodsScreen`)
- Список привязанных карт (маскированный номер).
- Добавление новой карты через модальное окно с форматтерами (пробелы через каждые 4 цифры, валидация месяца/года).
- Удаление карты с уведомлением.

#### 5.8. Поддержка (`SupportScreen`)
- Список часто задаваемых вопросов (FAQ) с ответами.
- Контакты разработчиков (Telegram-теги).

### 6. Визуальное оформление

- **Тёмная тема:** фон `#0A0A0C`, акцентный цвет – `#FFC107` (жёлтый).
- **Стеклянные карточки:** `BackdropFilter` с размытием, полупрозрачный фон, тонкая обводка.
- **Свечение:** виджет `GlowOrb` для декоративных градиентных кругов.
- **Адаптивность:** используются `SafeArea`, `MediaQuery`, `Expanded` / `Flexible`.

### 7. Примечания по API и ограничениям

- **Nominatim** имеет ограничение ~1 запрос в секунду (без API-ключа). Для коммерческого использования рекомендуется собственный сервер или получение ключа.
- **OSRM** – публичный сервер, не гарантирует стабильность при высокой нагрузке.
- **Open-Meteo** – бесплатный, без ключа, но с ограничением на количество запросов.
- **Картографические тайлы** OpenStreetMap требуют указания атрибуции в production-версии.
