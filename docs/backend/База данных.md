# Архитектура микросервисного приложения для такси

## Сервисы

1. **API Gateway**
2. **User Service**
3. **Trip Service**
4. **Payment Service**
5. **Notification Service**

---

## 1. API Gateway

Единая точка входа. Валидирует JWT токен через User Service, маршрутизирует запросы, делает rate limiting. Своей базы данных нет.

---

## 2. User Service

Объединяет авторизацию и профили пассажиров и водителей в одном месте.

### Таблицы

**accounts**

| Колонка       | Тип       | Описание           |
| ------------- | --------- |--------------------|
| id            | UUID PK   | Идентификатор      |
| role          | ENUM      | user, admin        |
| email         | VARCHAR   | Email              |
| phone         | VARCHAR   | Телефон            |
| password_hash | VARCHAR   | Хэш пароля         |
| is_active     | BOOLEAN   | Не заблокирован ли |
| created_at    | TIMESTAMP | Дата регистрации   |

**refresh_tokens**

| Колонка    | Тип       | Описание           |
|------------|-----------|--------------------|
| id         | UUID PK   | Идентификатор      |
| account_id | UUID FK   | Ссылка на accounts |
| token_hash | VARCHAR   | Хэш токена         |
| expires_at | TIMESTAMP | Когда истекает     |
| revoked    | BOOLEAN   | Отозван ли         |

**passenger_profiles**

| Колонка        | Тип          | Описание           |
| -------------- | ------------ | ------------------ |
| account_id     | UUID PK FK   | Ссылка на accounts |
| first_name     | VARCHAR      | Имя                |
| last_name      | VARCHAR      | Фамилия            |
| photo_url      | VARCHAR      | Фото               |
| average_rating | DECIMAL(3,2) | Средний рейтинг    |
| total_trips    | INTEGER      | Количество поездок |

**driver_profiles**

| Колонка        | Тип          | Описание              |
| -------------- | ------------ | --------------------- |
| account_id     | UUID PK FK   | Ссылка на accounts    |
| first_name     | VARCHAR      | Имя                   |
| last_name      | VARCHAR      | Фамилия               |
| photo_url      | VARCHAR      | Фото                  |
| license_number | VARCHAR      | Номер прав            |
| status         | ENUM         | online, offline, busy |
| average_rating | DECIMAL(3,2) | Средний рейтинг       |
| total_trips    | INTEGER      | Количество поездок    |
| is_verified    | BOOLEAN      | Верифицирован ли      |

**vehicles**

| Колонка       | Тип      | Описание                   |
|---------------|----------|----------------------------|
| id            | UUID PK  | Идентификатор              |
| driver_id     | UUID FK  | Ссылка на driver_profiles  |
| brand         | VARCHAR  | Марка                      |
| model         | VARCHAR  | Модель                     |
| year          | SMALLINT | Год выпуска                |
| color         | VARCHAR  | Цвет                       |
| license_plate | VARCHAR  | Госномер                   |
| vehicle_class | ENUM     | economy, comfort, business |
| is_active     | BOOLEAN  | Активный автомобиль        |

**driver_locations**

| Колонка    | Тип           | Описание                  |
| ---------- | ------------- | ------------------------- |
| driver_id  | UUID PK FK    | Ссылка на driver_profiles |
| latitude   | DECIMAL(10,7) | Широта                    |
| longitude  | DECIMAL(10,7) | Долгота                   |
| updated_at | TIMESTAMP     | Время обновления          |

## 3. Trip Service

Управляет поездками, статусами, тарифами, рейтингами и подбором водителя. Подбор водителя — это просто запрос к User Service за списком ближайших онлайн водителей, никакой отдельной сложной логики.

### Таблицы

**trips**

| Колонка             | Тип           | Описание                                                               |
|---------------------|---------------|------------------------------------------------------------------------|
| id                  | UUID PK       | Идентификатор                                                          |
| passenger_id        | UUID          | Пассажир                                                               |
| driver_id           | UUID          | Водитель — null до назначения                                          |
| status              | ENUM          | created, searching, driver_assigned, in_progress, completed, cancelled |
| trip_class          | ENUM          | economy, comfort, business                                             |
| origin_address      | TEXT          | Адрес подачи                                                           |
| origin_lat          | DECIMAL(10,7) | Широта подачи                                                          |
| origin_lng          | DECIMAL(10,7) | Долгота подачи                                                         |
| destination_address | TEXT          | Адрес назначения                                                       |
| destination_lat     | DECIMAL(10,7) | Широта назначения                                                      |
| destination_lng     | DECIMAL(10,7) | Долгота назначения                                                     |
| distance_km         | DECIMAL(6,2)  | Расстояние                                                             |
| duration_min        | SMALLINT      | Время в минутах                                                        |
| weather_coefficient | DECIMAL(3,2)  | Коэффициент погоды                                                     |
| surge_multiplier    | DECIMAL(3,2)  | Коэффициент спроса                                                     |
| price_breakdown     | JSONB         | Информация о цене (генерируется после выбора тарифа)                   |
| price               | DECIMAL(10,2) | Цена поездки                                                           |
| payment_id          | UUID          | Ссылка на транзакцию                                                   |
| created_at          | TIMESTAMP     | Дата создания                                                          |
| updated_at          | TIMESTAMP     | Дата обновления                                                        |

**trip_status_history**

| Колонка         | Тип       | Описание                  |
|-----------------|-----------|---------------------------| 
| id              | UUID PK   | Идентификатор             |
| trip_id         | UUID FK   | Ссылка на trips           |
| previous_status | ENUM      | Предыдущий статус         |
| new_status      | ENUM      | Новый статус              |
| changed_by      | ENUM      | passenger, driver, system |
| created_at      | TIMESTAMP | Дата изменения            |

**tariffs**

| Колонка       | Тип          | Описание                   |
|---------------| ------------ |----------------------------|
| id            | UUID PK      | Идентификатор              |
| trip_class    | ENUM         | economy, comfort, business |
| base_fare     | DECIMAL(8,2) | Базовая ставка             |
| price_per_km  | DECIMAL(8,2) | Цена за км                 |
| price_per_min | DECIMAL(8,2) | Цена за минуту             |
| is_active     | BOOLEAN      | Активен ли тариф           |

**ratings**

| Колонка    | Тип       | Описание          |
|------------|-----------|-------------------|
| id         | UUID PK   | Идентификатор     |
| trip_id    | UUID FK   | Ссылка на trips   |
| rated_by   | ENUM      | passenger, driver |
| rater_id   | UUID      | Кто оценил        |
| ratee_id   | UUID      | Кого оценили      |
| score      | SMALLINT  | Оценка от 1 до 5  |
| comment    | TEXT      | Комментарий       |
| created_at | TIMESTAMP | Дата оценки       |

## 4. Payment Service

Проводит платежи через Stripe, хранит платёжные методы и историю транзакций.

### Таблицы

**payment_methods**

| Колонка                  | Тип        | Описание                  |
|--------------------------|------------|---------------------------|
| id                       | UUID PK    | Идентификатор             |
| passenger_id             | UUID       | Пассажир                  |
| stripe_customer_id       | VARCHAR    | ID клиента в Stripe       |
| stripe_payment_method_id | VARCHAR    | ID метода оплаты в Stripe |
| card_brand               | VARCHAR    | Visa, Mastercard          |
| last_four                | VARCHAR(4) | Последние 4 цифры         |
| is_default               | BOOLEAN    | Основной метод            |
| is_active                | BOOLEAN    | Не удалён ли              |
| created_at               | TIMESTAMP  | Дата добавления           |

**transactions**

| Колонка                  | Тип           | Описание                             |
| ------------------------ | ------------- | ------------------------------------ |
| id                       | UUID PK       | Идентификатор                        |
| trip_id                  | UUID          | Идентификатор поездки                |
| passenger_id             | UUID          | Плательщик                           |
| driver_id                | UUID          | Получатель                           |
| type                     | ENUM          | charge, refund, payout               |
| amount                   | DECIMAL(10,2) | Сумма                                |
| currency                 | VARCHAR(3)    | Валюта                               |
| status                   | ENUM          | pending, succeeded, failed, refunded |
| stripe_payment_intent_id | VARCHAR       | ID в Stripe                          |
| payment_method_id        | UUID FK       | Использованный метод                 |
| created_at               | TIMESTAMP     | Дата создания                        |

**driver_payout_accounts**

| Колонка           | Тип        | Описание                   |
|-------------------|------------|----------------------------|
| id                | UUID PK    | Идентификатор              |
| driver_id         | UUID       | Водитель                   |
| stripe_account_id | VARCHAR    | ID аккаунта Stripe Connect |
| last_four         | VARCHAR(4) | Последние цифры реквизита  |
| is_verified       | BOOLEAN    | Верифицирован в Stripe     |
| is_default        | BOOLEAN    | Основной реквизит          |
| created_at        | TIMESTAMP  | Дата добавления            |

## 5. Notification Service

Фоновый сервис. Читает очередь задач и отправляет уведомления через push, SMS или email. При неудаче делает повторные попытки.

### Таблицы

**notification_tasks**

| Колонка        | Тип       | Описание                                                                       |
| -------------- | --------- | ------------------------------------------------------------------------------ |
| id             | UUID PK   | Идентификатор                                                                  |
| trip_id        | UUID      | Идентификатор поездки                                                          |
| event_type     | ENUM      | driver_assigned, trip_started, trip_completed, payment_charged, trip_cancelled |
| recipient_type | ENUM      | passenger, driver                                                              |
| recipient_id   | UUID      | Кому отправить                                                                 |
| channel        | ENUM      | push, sms, email                                                               |
| message        | TEXT      | Текст сообщения                                                                |
| status         | ENUM      | pending, sent, failed                                                          |
| created_at     | TIMESTAMP | Дата создания                                                                  |
