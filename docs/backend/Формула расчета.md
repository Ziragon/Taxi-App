# Формула расчета цены за поездку

```
final_price = (base_fare + km * price_per_km + min * price_per_min) * surge * weather_k
```

---
## Параметры рассчитывания

- `base_fare` - базовая цена за тип тарифа (эконом, бизнес и т.д.)
- **OSRM**, расположенный на нашем сервере локально будет 
по координатам рассчитывать маршрут и выдавать
`distance_km` (`km`) и `duration_min` (`min`)" параметры - основа расчета
- `weather_k` будет исходить из открытого API с информацией о погоде 
и максимально упрощено влиять на тариф
  - **Ясно**: 1.0
  - **Дождь**: 1.1
  - **Сильный дождь/снег**: 1.2
  - **Гроза/метель**: 1.3
- `surge` - способ имитации спроса
  - **Ночь 0:00-6:00**: 1.2
  - **Час-пик 8:00–10:00 и 17:00–20:00**: 1.15
  - **Остальное**: 1.0
